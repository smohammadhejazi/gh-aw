# gh-aw

A repository using [GitHub Agentic Workflows](https://github.com/github/gh-aw) to automate repository tasks.

## Latest Changes

This push adds a README update workflow and associated configuration files, and includes small updates to `README.md` and `main.py`.

## Workflows

- **update-readme**: On every push to `main`, summarizes the change and opens a pull request updating this README's "Latest Changes" section.
